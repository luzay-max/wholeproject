# 管理员模块开发计划

## 一、接口配置与转发分析

### 1. 全局API配置
- **配置文件**：`src/api/request.js`
- **baseURL**：从环境变量 `VITE_APP_BASE_API` 获取，默认值为 `/api`
- **请求拦截器**：自动添加token到请求头
- **响应拦截器**：统一处理错误和状态码，401未授权时自动跳转到登录页
- **超时时间**：10秒

### 2. 环境配置
- **开发环境**：`.env.development`
  - API基础URL：`http://localhost:8080/api`
  - 开发服务器端口：5174

### 3. Vite代理配置
- **代理规则**：将 `/api` 请求转发到 `http://localhost:8080`
- **配置特点**：
  - 保留原始路径，不需要重写
  - 转发所有必要的请求头（Authorization、Content-Type）
  - 支持WebSocket热更新（HMR）

## 四、管理模块开发

### 1. 通用组件设计
- **数据表格组件**：支持筛选、分页、排序
- **操作按钮组件**：统一操作按钮样式和行为
- **弹窗表单组件**：用于编辑和添加数据

### 2. 用户管理模块

#### 功能需求
- 显示所有用户列表
- 支持按用户名、角色、注册时间筛选
- 支持用户信息编辑
- 支持用户角色修改
- 支持用户禁用/启用
- 支持用户删除

#### 后端API需求
```
GET /admin/users - 获取用户列表
  - 参数：page, pageSize, username, role, startTime, endTime
  - 响应：{ code: 0, data: { list: [], total: 0 } }

PUT /admin/users/:id - 更新用户信息
  - 请求体：{ username, name, phone, email }
  - 响应：{ code: 0, message: '更新成功' }

PUT /admin/users/:id/role - 修改用户角色
  - 请求体：{ role }
  - 响应：{ code: 0, message: '角色修改成功' }

PUT /admin/users/:id/status - 修改用户状态
  - 请求体：{ status }
  - 响应：{ code: 0, message: '状态修改成功' }

DELETE /admin/users/:id - 删除用户
  - 响应：{ code: 0, message: '删除成功' }
```
